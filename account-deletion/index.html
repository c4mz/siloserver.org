Delete a Silo account

Last updated August 12, 2026

Silo Media Player does not provide or host centralized user accounts. An account created in the app belongs to the self-hosted Silo server selected by the user. That server's operator—not the Silo project—controls the account and its associated data.

Request deletion from your server operator

  1. Identify the person or organization that gave you the Silo server address, invitation, or login. That is normally the server operator.
  2. Contact that operator and ask them to delete your Silo user account and associated data.
  3. Give the operator the username or email address used on that server so they can locate the correct account. Share the server address and account details only with that operator—not with the Silo project.

The Silo project cannot identify the operator of an arbitrary self-hosted server, access its administration tools, verify its users, or delete data from it.

Instructions for a Silo server administrator

  1. Sign in to the self-hosted Silo web application as an administrator.
  2. Open Administration → Users.
  3. Select the requesting user and choose Delete user.
  4. Confirm the permanent deletion.

Account deletion is performed by the self-hosted server. It does not send account information or a deletion request to the Silo project.

Data deleted from the live server

Deleting a user removes the account from the live Silo database and invalidates its active sessions. Associated user-scoped records are also deleted, including, where present:

  • profiles and profile access assignments;
  • authentication sessions, API keys, and registered device records;
  • settings and preferences;
  • watch history, playback progress, ratings, favorites, and watchlist;
  • personal collections and related user-created state; and
  • user-scoped download, notification, request, and synchronization state.

Data that may be kept

A server operator may retain backups, security logs, audit records, or information required by law or legitimate security needs. The operator determines those retention periods and is responsible for explaining them to the user. Some shared library metadata or administrative records may remain without being associated with the deleted account.

Data stored on your device

Removing a server from Silo Media Player, signing out, clearing the app's storage, or uninstalling the app removes the applicable local credentials, caches, settings, and downloaded media. These actions do not delete the account held by the self-hosted server; the server operator must still complete the steps above.

Silo-managed diagnostics and push delivery

Optional Silo-managed diagnostic reports are not linked to an account on a self-hosted server, so deleting that account does not identify or delete a previously sent report. Diagnostic reports expire within 30 days. To request earlier report deletion, email feedback@siloserver.org and include the report reference shown in the app.

The content-free Silo push relay does not hold self-hosted account records. Revoking a device or deleting the user on the self-hosted server stops that server from sending future pushes for the deleted account.

Questions

Questions about these instructions may be sent to feedback@siloserver.org. Do not send your password, authentication token, private server address, or other account credentials. Silo cannot forward a deletion request to an unknown self-hosted server operator.
